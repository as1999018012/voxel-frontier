# ボクセルフロンティア (Voxel Frontier)

Java + LWJGL 3 (OpenGL 3.3) で作った Minecraft 風のボクセルゲーム。
専有サーバーを持たず、プレイヤーの1人がホストになって遊ぶマルチプレイに対応している。

- 対象機種: Windows 11 (x64) / Linux aarch64 (PGX)
- 必要なもの: JDK 21、OpenGL 3.3 に対応したGPU

## 起動

```
./gradlew run                              # 1人プレイ (Windows は .\gradlew run)
./gradlew run --args="--host"              # ホストとして開始
./gradlew run --args="--join"              # LAN内のホストを自動で探して参加
./gradlew run --args="--join 192.168.1.10" # アドレスを指定して参加
./gradlew run --args="--help"              # オプション一覧
```

主なオプション:

| オプション | 内容 |
|---|---|
| `--name <名前>` | プレイヤー名 (既定: OSのユーザー名) |
| `--world <名前>` | ワールド名。`saves/<名前>/` に保存される (既定: `world`) |
| `--seed <数値>` | 新しいワールドのシード |
| `--port <番号>` | 待ち受け/接続ポート (既定: 24454) |
| `--upnp` | ホスト時、ルーターにUPnPでポート開放を依頼する |
| `--render-distance <数>` | 描画距離 [チャンク] (既定: 8) |

## 操作

| 操作 | 内容 |
|---|---|
| クリック | マウスを捕捉して操作開始 |
| マウス | 視点移動 |
| W / A / S / D | 移動 |
| Space | ジャンプ (水中では浮上、飛行中は上昇) |
| 左Shift | 飛行中の下降 |
| 左Ctrl | ダッシュ |
| F | 飛行モードの切り替え |
| 左クリック / 右クリック | ブロックを壊す / 置く |
| 1〜9 / ホイール | 置くブロックを選ぶ |
| F2 | スクリーンショット (`screenshots/` に保存) |
| F6 | 1人プレイ中のワールドをLANに公開する (ホストになる) |
| ESC | マウス捕捉を解除 (解除中にもう一度押すと終了) |

座標・時刻・選択中のブロック・接続状態はウィンドウのタイトルバーに表示される。
ワールドは60秒ごとと終了時に自動保存される (ホスト/1人プレイのみ)。

## マルチプレイ

ホスト型 (リスンサーバー) 方式。ホストのゲームがワールドの「正」を持ち、参加者の操作を検証してから全員に配る。
地形はシードから各自が再生成するので、通信するのはシードと「変更されたブロック」だけ。

### 同じLAN内で遊ぶ

1. ホスト: `--host` で起動する (1人プレイ中に F6 を押してもよい)
2. 参加者: `--join` で起動すると、LAN内のホストを自動で見つけて参加する
3. 見つからない場合は、ホストのコンソールに出る「LAN内の参加者はこのアドレスへ」のアドレスを `--join <アドレス>` で指定する

初回のホスト起動時に Windows ファイアウォールの許可を求められたら、「プライベートネットワーク」を許可すること。

### インターネット越しに遊ぶ

1. ホスト: `--host --upnp` で起動する。成功するとコンソールに友達へ伝えるアドレスが表示される
2. UPnP が使えないルーターでは、ルーターの設定で TCP 24454 をホストのPCへ転送 (ポート開放) する
3. 参加者: `--join <ホストのグローバルIP>` で参加する

ホストが終了すると、全員のセッションが終了する (ホストの引き継ぎは未対応)。

## 配布

```
./gradlew installDist
```

`build/install/voxel-frontier/` を丸ごと渡せば、JDK 21 が入ったPCで `bin/voxel-frontier` (Windows は `bin\voxel-frontier.bat`) から起動できる。
LWJGL のネイティブライブラリは Windows / Linux x64 / Linux aarch64 の分をすべて同梱しているので、どの機種でビルドした配布物でも両方の対象機種で動く。

## 開発

```
./gradlew test    # 地形生成・メッシュ生成・当たり判定・通信などの自動テスト
```

`TerrainGeneratorTest.checksumMatchesAcrossPlatforms` は、地形がどの機種でもビット単位で同じになることを確かめるテスト。
地形生成を変更したら、Windows で出たチェックサムに基準値を更新し、PGX でも同じテストが通ることを確認する。

| パッケージ | 内容 |
|---|---|
| `voxelfrontier` | 起動 (`Main`)、オプション、ゲームループ (`Game`) |
| `voxelfrontier.world` | ブロック、チャンク、地形生成、ワールド、保存、視線判定 |
| `voxelfrontier.entity` | プレイヤーの移動と当たり判定 |
| `voxelfrontier.render` | OpenGL 描画 (チャンクメッシュ、テクスチャ、HUD など) |
| `voxelfrontier.net` | 通信 (パケット、ホスト、参加者、LAN検出、UPnP) |
